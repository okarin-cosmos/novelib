# NoveLib 作品カタログ

NoveLibに同梱する作品マスターは、VNDBの公開データベースダンプから生成しています。

- 出典: https://vndb.org/
- 使用ダンプ: 2026-09-03 08:00:10 UTC
- データベースライセンス: Open Database License 1.0（ODbL）
- コンテンツライセンス: Database Contents License 1.0（DbCL）
- 抽出条件: 原作言語が日本語、かつ開発中止ではない作品
- 収録件数: 37,493作品

## 収録する項目

- VNDB ID
- 日本語正式名称
- ローマ字表記
- 別名
- 初回発売日
- ブランド／開発元
- VNDB参考評価と投票数
- 作品画像URL
- 対象年齢とR18区分

R18区分は、日本語の公式リリースに `minage >= 18` または成人向け内容の
指定がある場合に設定します。37,493作品中23,815作品が該当します。

## 販売サイト商品ID

将来の作品ランキングからFANZA・DLsiteへ案内できるよう、カタログに
`store_products` 表を用意しています。1作品へ同一ストアの複数商品を
紐付けられ、ストア名、商品ID、通常のリンク先、優先商品、出典、確認日時を
保持します。アフィリエイトIDを含むURLは保存せず、提携設定から表示時に
生成します。現時点では誤照合を避けるため、商品IDデータ自体は未収録です。

説明文と画像ファイルは収録しません。作品画像URLだけをカタログへ収録し、
画像は表示時にVNDBの画像配信元から取得して端末内へキャッシュします。

## 評価サーバーの正式マスター

同じ `works` データからSupabase用migrationを生成し、VNDB ID、正式日本語名、R18区分を評価サーバーへ登録します。評価APIはこのマスターに存在するIDだけを受理し、クライアントが送る作品名・R18区分では公開情報を上書きしません。

再生成には `tools/export_supabase_catalog.py` を使用します。生成前にSQLiteの整合性、出典日時、最低作品件数を検証します。

生成済みSQLite、ODbL全文、DbCL全文は配布物に同梱します。再生成ツールは
tools/build_vndb_catalog.pyです。ユーザー固有の所有状況、評価、プレイ履歴、
フォルダパスは作品マスターには含めません。
